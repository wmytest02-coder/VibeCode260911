📝HTML5란?

HTML(HyperText Markup Language)은 웹 페이지의 구조를 정의하는 마크업 언어입니다. HTML5는 최신 표준으로 의미 있는 태그들이 추가되었습니다.

<!DOCTYPE html> <html> <head> <title>페이지 제목</title> </head> <body> <h1>제목</h1> <p>내용</p> </body> </html>

주요 HTML5 의미 있는 태그들:

<header>

페이지나 섹션의 헤더 정보를 포함합니다.

<nav>

네비게이션 링크들을 포함합니다.

<section>

문서의 독립적인 섹션을 정의합니다.

<footer>

페이지나 섹션의 푸터 정보를 포함합니다.

🎨CSS3란?

CSS(Cascading Style Sheets)는 HTML 요소들의 스타일과 레이아웃을 정의합니다. CSS3는 다양한 효과와 애니메이션을 제공합니다.

.box { width: 100px; height: 100px; background: linear-gradient(45deg, #ff6b6b, #ee5a6f); border-radius: 10px; transition: all 0.5s ease; } .box:hover { transform: scale(1.1); box-shadow: 0 10px 30px rgba(0, 0, 0, 0.3); }

CSS3의 주요 기능들을 체험해보세요:

Gradient
Transform
Animation

⚡JavaScript란?

JavaScript는 웹 페이지에 인터랙티브한 기능을 추가하는 프로그래밍 언어입니다. 사용자의 입력에 반응하고 동적으로 페이지를 변경할 수 있습니다.

function changeColor() { const box = document.getElementById('colorBox'); const colors = ['#FFB6C1', '#87CEEB', '#90EE90', '#FFD700']; const randomColor = colors[Math.floor(Math.random() * colors.length)]; box.style.backgroundColor = randomColor; }
